FIRST CANDIDATES — CONFIRM SCOPE WITH ROBERT, THEN PRIORITIZE

1. Thermostat installation, replacement and repair
   Competitor signal: Kindred and Gill's explicitly list thermostat work.
   Candidate: /services/heating/thermostats
   Cover: fault diagnosis versus equipment faults; compatible smart thermostats;
   wiring/power requirements; furnace and heat-pump/dual-fuel controls; setup and
   homeowner handoff. Link from heating, AC repair and heat-pump pages.
   Confirm: which thermostat brands/types and standalone jobs Robert accepts.
   One useful page can cover installation and repair; avoid several thin variants.

2. Ductwork repair, installation and airflow improvements
   Competitor signal: Kindred/Gill's list duct installation and repair; Northern
   and Falls Mechanical list duct installation.
   Candidate: /services/heating/ductwork-airflow
   Cover: uneven room temperatures, return/supply issues, leaks, accessible duct
   repairs, replacement/additions, and what assessment is included. Use actual
   examples and limitations; link from furnace and AC installation pages.
   Confirm: fabrication, sealing, repair and balancing work actually performed,
   access restrictions and any subcontracted work. Keep duct cleaning separate.

3. Indoor air quality, filtration and air-cleaner installation
   Competitor signal: Northern explicitly lists air purifiers and scrubbers.
   Candidate: /services/indoor-air-quality
   Cover: filter fit, pressure drop and airflow compatibility; smoke-season
   concerns; equipment choices and maintenance; realistic limitations.
   Confirm: which products/installations Robert offers. No unsupported health,
   mold-removal, pathogen-elimination or guaranteed indoor-air claims.
   Existing cooling guidance is a starting point, not proof of a new offering.

4. Dedicated non-emergency furnace repair page, if it adds distinct value
   Competitor signal: Kindred shows Furnace repair service; all four list
   heating repair. Our heating hub and emergency page already address repairs.
   Candidate: /services/heating/furnace-repair
   Cover: scheduled diagnosis, intermittent faults, findings, repair versus
   replacement and what customers should have ready for a service call.
   Differentiate from emergency call-first content and the heating hub. Expand
   existing pages first if a separate page would repeat them. No new GBP service
   entry is needed solely because a dedicated URL is added; repair is already listed.

5. Real project/case-study pages
   Candidate collection: /projects, with individual descriptive project URLs.
   Build from Robert's actual furnace, AC, heat-pump or ductless work: initial
   problem, equipment, work, photos and observed result. Obtain permission for
   customer/location details and testimonials. Never publish a private street
   address or attach unrelated images to a specific project.
   This is our evidence-building recommendation, not an observed competitor GBP
   service. Existing retrofit account is a potential starting point; distinguish
   measured cooling results from unmeasured winter savings.

REPEATABLE RELEASE CHECKLIST FOR EACH APPROVED OFFERING
1. Confirm Robert offers it, relevant qualifications, service area, equipment,
   availability and actual policies. Collect a real example/photo where possible.
2. Define the customer problem and distinct page purpose. Pick a useful URL and
   combine overlapping topics; do not publish repetitive service synonyms.
3. Write concrete scope, process, exclusions, decision guidance and real FAQs.
   Retain call-first emergency instructions and honest appointment expectations.
4. Link from the appropriate hub and related services; add canonical metadata,
   indexable sitemap entry and matching visible/schema content. Use the same
   existing business entity, contact details and service-area facts.
5. Update Google Business Profile with the same actual offering and accurate
   service description, using suggested service labels where suitable. Add a new
   category only if it describes the business, not merely a page topic.
6. Update relevant directories from the maintained listing register. Keep the
   street address hidden and consistent with the approved service-area setup.
7. Deploy, check actual rendered page/form/internal links and run the search
   validation script. Notify IndexNow only for newly published/changed URLs.
8. Measure impressions, searches and qualified inquiries. Reprioritize from real
   results rather than assuming competitor service-list length determines rank.
